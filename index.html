General Developer Privacy Policy
                            

                            Last
                                Updated: July 2026
                        

                        

                            This general developer privacy statement outlines how developer Saurabh
                            ("we", "us", or "our") manages user information. Protecting user privacy is of paramount
                            importance to us, and we design our applications with strict security and local data
                            principles.
                        

                        
1.
                            Information Collection & Usage

                        

                            Most applications published under our developer account are designed as
                            offline-first tools or local utilities. We do not host central databases
                            that collect, store, or transmit Personally Identifiable Information (PII). All user-created
                            configurations, profiles, and activities remain entirely on the local device storage.
                        

                        
2.
                            Third-Party Libraries & Services

                        

                            To optimize software stability, performance, or occasionally render native components, some
                            of our mobile applications may integrate standard third-party tools, including but not
                            limited to:
                        

                        
    
                            
  • Google Play Services: For native account authentication, installation
                                tracking, and basic system checks.
    • 
                            
  • Firebase Analytics: Anonymized crash logging and user session
                                diagnostics, which allow us to locate and patch crashes on specific device models.
    • 
                        

                        
3. Security
                            Protocols

                        

                            We employ standard cryptographic measures (such as local file system isolation) to safeguard
                            any data stored on your device. However, since the apps run locally, the safety of your data
                            also depends on your operating system security and system permissions.
                        

                    


                    
                    

                        

                            
Rehab Play (Finger Tap Game)
                                Privacy Policy

                            Play
                                Console Certified
                        

                        

                            Specifically applicable to the "Rehab Play — The Rehab House" motor-skill training
                            application.
                        

                        
1.
                            Personal Data and Game Progress

                        

                            Rehab Play is a cognitive and rehabilitation utility created to evaluate finger tapping
                            speed and reflexes. The application does not request sign-up, email details, or name
                                registration. All performance stats, timing logs, and test results are computed
                            locally inside the secure application sandbox and are never shared or transmitted.
                        

                        
2. Required
                            Permissions

                        

                            Rehab Play requests standard permissions for Service Worker/PWA Caching to
                            support offline play, and local browser storage. No dangerous permissions (such as
                            microphone, contacts, location, or camera access) are requested or required.
                        

                        
3. Cache and
                            Local Storage Data

                        

                            We utilize HTML5 LocalStorage to save your tap speed records. You can purge all saved data
                            at any time by clearing the application cache/storage in your device settings.
                        

                    


                    
                    

                        

                            
ScribaX Code Editor Privacy
                                Policy

                            Play
                                Console Certified
                        

                        

                            Specifically applicable to the "ScribaX" code editor web & mobile workspace.
                        

                        
1. Developer
                            Code and Inputs

                        

                            ScribaX operates entirely as a local workspace. Any code, text, or script inputs edited
                            inside the Monaco Editor interface are processed client-side. We do not collect, view,
                            index, or store your project files or source code.
                        

                        
2. File
                            System Access

                        

                            On platforms supporting the File System Access API, ScribaX may request authorization to
                            load or write files from directories you explicitly select. This access is temporary, runs
                            through native system dialogue prompts, and is not recorded on any remote servers.
